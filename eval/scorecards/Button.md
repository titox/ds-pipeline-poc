## To fix in code

Nothing here gates the verdict.

- src/ui/primitives/Button/Button.tsx:95-104 a link Button is not activated by Space. Measured: `<Button href="#x">` renders `<a href>`; Enter fires `onPress` and navigates, Space fires nothing. The rubric's walk-through says "activate with Enter and Space"; I did not count this as a failure because the element is a real link, Enter-only is the native and WAI-ARIA behaviour for the link role, and the pass condition ("fully usable by keyboard") holds. It is still a control that looks like a button and ignores Space. Decide with the designer whether `href` should stay on this component at all: the Figma description says "For navigation to another page, use a link rather than this component".
- src/ui/primitives/Button/Button.tsx:98 a loading link and a loading button behave differently. Measured: loading `<button>` stays in the Tab order (`aria-disabled="true"`, `tabindex="0"`); loading link becomes `<span role="link" aria-disabled="true">` with no tab stop, and the unused `href` attribute stays on the span. Both block activation, so not gating. Expected: one behaviour for Loading.
- src/ui/primitives/Button/button.css:9 a loading `<button>` keeps `cursor: pointer` although presses are blocked (the loading link gets `cursor: default` through button.css:103-106). Not specified in Figma, not gating.
- src/ui/primitives/Button/Button.tsx:84 Loading is not announced. Measured: `aria-disabled="true"` only, no `aria-busy`, no status text; the spinner SVG has no `aria-hidden` and `animation-name: none` (it does not spin). Axe passes and the rubric has no test for it. Motion needs a design decision first.
- src/ui/primitives/Button/Button.tsx:74 the `style` prop is accepted by the type and discarded (`style: _style`), read from the source, not measured in the browser. Remove it from the type or pass it on.
- src/ui/primitives/Button/Button.tsx:108-115 with `type="submit"` inside a form, Space fires `onPress` twice (Enter and mouse fire it once; the form submits once). Measured the same on a bare `react-aria-components` 1.13.0 `Button`, so it comes from the library, not from this file. Worth knowing before a submit Button gets an `onPress` handler.
- src/figma/primitives/button/Button.figma.ts:2 the `source=` URL contains a GitHub account name (373 such lines under `src/figma/`). Check it against the "keep the repo anonymous" rule in `CLAUDE.md`. Not part of the rubric.

## Design issues (for the designer)

None of these gates the verdict; the code matches Figma on each.

- Disabled text in light mode is 1.49:1 (`Text/Disabled/On Disabled` #b3b3b3 on `Background/Disabled/Default` #d9d9d9, variants `State=Disabled`). Exempt under WCAG but hard to read. Dark is 5.59:1.
- Subtle Hover (`Variant=Subtle, State=Hover`) is shown by a `Border/Default/Default` outline at 1.41:1 against the page in light and 1.71:1 in dark, plus text #303030 -> #1e1e1e. Close to invisible. Primary and Neutral hover are also slight (fill change 1.19:1 and 1.24:1 in light).
- Focus ring uses `Border/Focus/Default` = #ec221f (Red/500) in both modes. It passes 3:1 everywhere, lowest 3.03:1 against the Neutral fill in dark, but a red ring can read as an error.
- In the 6 Focus and 6 Loading variants no layer has a component property reference: the label is not connected to `Label`, and the icon layers are not connected to `Has Icon Start`, `Icon Start`, `Has Icon End`, `Icon End` (the other 18 variants have all five). Changing the label or icons on a focused or loading instance does nothing in Figma, and Figma does not say whether the end icon hides while loading. The code hides it.
- The component set description is out of date: "24-variant" and "four interaction states"; the set has 30 variants and a Loading state. It also mentions `Icon/Danger/Tertiary`, which is bound on none of the 30 variants.
- Loading has no specification for motion, for hover, or for how the state is announced.
- No Pressed state is designed (the contract lists it as missing). The code has no pressed style either.
- Small is 67x32px in Figma (65.3x32 in code): above the 24px minimum, below the 44px recommendation.
