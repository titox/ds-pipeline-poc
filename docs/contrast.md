# Contrast of the colour tokens

Generated by `npm run contrast` from `src/theme.css` and the rules in `scripts/contrast-pairs.json`. Do not edit by hand.

Minimums (WCAG 2.2 AA): text 4.5:1, icons and borders 3:1. Tokens with `disabled` in the name are exempt and listed apart.

The pairs are built from the token names. A pair listed here may not be used by any component: to see only the pairs of one component, run `npm run contrast -- <Name>`.

## Rules

- **on-colour:** Text and icon tokens named <role>-on-<role>, with or without -secondary or -tertiary, against the background of the same role and level, and its hover.
- **on-surface:** Every other text and icon token against each surface.
- **border-on-surface:** Every border token against each surface. The 3:1 minimum applies where the border is the only thing that marks a control (a field, a checkbox). A decorative border may fail it.
- **Surfaces:** Background Default Default, Background Default Secondary.
